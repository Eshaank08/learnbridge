# LearnBridge

> Free, expert-taught education for any student, anywhere — powered by a gamified skill-tree and AI-generated mastery tests.

**Claude Builders Club Hackathon** | Theme: Education | Branch: `graph`

---

## What it is

LearnBridge is a learning-graph / skill-tree app. Topics are **nodes**; directed edges encode
prerequisites. Each node progresses through **unlit → lit → mastered**, where mastery is earned
by passing an AI-generated quiz graded by Claude. Two seeded subject roadmaps ship out of the box:

- **Mathematics** — Arithmetic through Differential Equations (~12 nodes, real branching)
- **Biology** — Cell Biology through Genetics (5 nodes, includes Photosynthesis)

Student progress lives in **browser `localStorage`** — no database, no login required.

## Quick Start

### Backend

```bash
cd backend
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env          # defaults are offline-safe (MOCK_MODE=true)
uvicorn main:app --reload
```

Backend is now running at **http://localhost:8000**. Verify with `GET /health` → `{"status":"ok"}`.

The default `.env` sets `MOCK_MODE=true` — the whole quiz loop (including pass and fail paths)
works with no API key and no network.

### Frontend

```bash
cd frontend
npm install
cp .env.example .env.local    # sets NEXT_PUBLIC_API_URL=http://localhost:8000
npm run dev
```

Frontend is now running at **http://localhost:3000**.

Open the landing page, pick a graph, click a node, and take the quiz.

### Unit tests

```bash
cd frontend && npx vitest run
```

## Mock vs live Claude

| Mode | How to activate | What happens |
|---|---|---|
| **Backend mock** (default) | `MOCK_MODE=true` in `backend/.env` | Template questions generated from the node's own title/summary; MCQ graded deterministically; short answers graded as correct if non-empty. Fully offline. |
| **Live Claude** | `MOCK_MODE=false` + valid `ANTHROPIC_API_KEY` | Questions generated by `claude-sonnet-4-6` via structured outputs (Pydantic); short answers graded by Claude against the node summary. MCQ still graded deterministically in Python. |
| **Frontend client mock** | `NEXT_PUBLIC_CLIENT_MOCK=true` in frontend env | `lib/api.ts` returns local fixtures without any network call — backend need not be running. |

**Demo fallback chain:** live Claude → backend `MOCK_MODE` → frontend `NEXT_PUBLIC_CLIENT_MOCK`.

Note: the live Claude path is implemented (structured outputs, `client.messages.parse`) but has
not been verified end-to-end without a key — use mock mode for the demo unless you have a key handy.

## Architecture

```
frontend/   Next.js 14 (App Router, TypeScript, Tailwind) + React Flow canvas
backend/    Python FastAPI — touched ONLY for the AI mastery quiz (generate + grade)
seed-data/  graphs.json — graph structure, materials, and quiz settings (client-imported)
```

**Data-flow:**
- Graph structure and materials are imported **client-side** from `seed-data/graphs.json` — instant, works offline.
- The backend is invoked for exactly one thing: `POST /api/test/generate` and `POST /api/test/grade`.
- Progress (node states) is stored in `localStorage` under the key `learnbridge:<graphId>:v1`.
- A **Reset** button on the canvas clears progress for the current graph without a page reload.

**Node states:** `unlit` (not yet opened) → `lit` (opened, reading in progress) → `mastered` (quiz passed). A fourth visual state, `locked` (dimmed + lock icon), is derived at render time from the prerequisite graph — it is never stored.

## API endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/health` | Liveness check |
| `POST` | `/api/test/generate` | Generate quiz questions for a node |
| `POST` | `/api/test/grade` | Grade submitted answers |

Both POST endpoints accept `{"graph_id": "math", "node_id": "calculus", ...}` — see `backend/main.py` for full request/response shapes.
